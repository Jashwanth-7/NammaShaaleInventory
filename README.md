# Namma-Shaale Inventory

An Android application developed for managing school inventory efficiently using Generative AI features.

## Features
- Inventory management
- Add and update stock details
- Track school resources
- User-friendly Android interface
- AI-assisted functionalities

## Technologies Used
- Kotlin
- Android Studio
- Firebase
- Room Database
- GenAI APIs
