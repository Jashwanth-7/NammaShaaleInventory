# Namma-Shaale Inventory

Namma-Shaale Inventory is an Android application developed for educational institutions to manage and monitor school inventory efficiently. The application allows teachers and administrators to register assets, update item conditions, and track inventory records digitally.

## Features

- User Authentication (Login & Signup)
- Role-Based Access
  - Admin Dashboard
  - Teacher Dashboard
- Asset Registration
- Inventory Tracking
- Search and Filter Assets
- Update Asset Conditions
- Real-Time Inventory Summary
- Modern UI using Jetpack Compose

## Tech Stack

- Kotlin
- Android Studio
- Jetpack Compose
- MVVM Architecture
- Navigation Component
- Room Database
- Material 3 Design

## Project Structure

- `MainActivity.kt` - Navigation and UI screens
- `ViewModel` - Business logic and state management
- `Room Database` - Local data storage
- `Compose UI` - Modern declarative UI components

## Asset Conditions

- Working
- Needs Repair
- Broken

## User Roles

### Admin
- View inventory summary
- Access detailed inventory list
- Monitor asset conditions

### Teacher
- Register new assets
- Update asset conditions
- View inventory details
